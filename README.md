# GhostNet

A lightweight web security analysis tool that evaluates URLs using crawling, network checks, and AI-assisted analysis.

## Features

* URL and domain security analysis
* Safe web crawling with boundary checks
* Internal network request protection
* Trust-score evaluation
* AI-assisted analysis with Gemini
* Supabase-backed data handling
* FastAPI backend with React frontend

## Tech Stack

* Python
* FastAPI
* React
* Vite
* Supabase
* Google Gemini

## Setup

```bash
git clone <repository-url>
cd GhostNet

pip install -r requirements.txt
```

Create a `.env` file with the required API credentials, then start the backend and frontend.
